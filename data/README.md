# Scientific data

`spectral-lines.json` is the canonical data source for both the book and the
website. Each record should carry source keys and an explicit wavelength or
frequency convention. Generated files must not be edited by hand.

The catalogue is educational and discovery-oriented. It is not a replacement
for a precision query to NIST ASD, Splatalogue, CDMS, JPL, or the primary paper
appropriate to a particular transition.
